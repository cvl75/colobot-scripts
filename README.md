# colobot-scripts
Some useful script for Colobot.

I keep main scripts in private folder ( ~/.local/share/colobot/savegame/XXXingamenameXXX/program ) - tested with Colobot: Gold Edition on Ubuntu 18.10.

Add all scripts in usefull folder to colobot script public folder ( ~/.local/share/colobot/program ).


## OR

1. Add all_in_1.txt in savegame or public program folder. This script contains all functions needed with "public" declaration.
2. Load this script in the first/{most protected} grabber
3. update grabber function main
4. All other grabbers/bots need only one new main function
